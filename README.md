# Travel Site

A responsive, mobile-first travel website built with HTML, CSS, JavaScript, jQuery, Webpack, and Gulp.

This project was completed while following Brad Schiff's **Git a Web Developer Job: Mastering the Modern Workflow** course. It demonstrates responsive web design, image optimization, modern front-end build tools, and deployment using GitHub Pages.

Although this is one of my earliest web development projects, I have intentionally preserved it as part of my portfolio to illustrate my progression from front-end development into full-stack software engineering.

## Project Overview

This application demonstrates many of the core concepts of modern front-end web development, including responsive design, performance optimization, asset bundling, and automated build workflows.

### Features

- Responsive, mobile-first layout
- Responsive images with resolution switching
- Lazy loading of images and SVG sprites
- Smooth scrolling navigation
- Reveal-on-scroll animations
- Performance optimization for mobile devices
- Cross-browser compatibility enhancements
- Automated development workflow using Gulp and Webpack
- Live browser reloading with BrowserSync
- Deployment with GitHub Pages

## Getting Started

Clone the repository:

```bash
git clone https://github.com/JMishock/travel-site.git
```

Install dependencies:

```bash
npm install
```

or

```bash
yarn install
```

Start the development server:

```bash
gulp watch
```

The application will automatically open in your browser.

If it does not, navigate to:

```
http://localhost:3000
```

BrowserSync also provides an external URL for testing on additional devices connected to the same network.
